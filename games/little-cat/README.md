# 猫咪小屋

独立静态的原创 2D 猫咪养成游戏，无框架、无安装、无远程字体/CDN。HTML、CSS、JS 与 SVG 合计约 61 KB（未压缩）。GitHub Pages / Jekyll 可直接发布 `/games/little-cat/`。

## 玩法与保存

- 摸头、喂食、洗澡、睡觉，四项状态、成长等级、星星和互动次数。
- 玩耍：20 秒内点到移动毛线球 5 次，获得成长和星星。
- 衣橱：3 种毛色和 3 种配饰，皮肤购买仅消耗游戏内星星。
- 本机 localStorage 自动保存；多个同源页面通过 storage 事件同步。关闭浏览器后也能继续，离线状态衰减最多计算 8 小时。
- “保存猫咪照片”生成存档卡，点击“下载原始 PNG”，或在支持 Web Share 的手机使用分享按钮。网页无法保证每种安卓浏览器会直接放入相册；有的需要从下载目录移动到相册。
- 新页面点击“从照片接回猫咪”，选择 PNG，先校验再显示预览，确认后恢复。导入只在本机读取，不向服务器上传。恢复保留存档状态，时间基准重新设为导入时刻，便于迁移后继续养成。

## 单 PNG 像素存档协议 v1

**只有一个文件，没有 JSON 或校验码侧文件。** 卡片为 512×512 PNG，在 `(32,416)` 起的 448×64 区域内，以每像素 RGB 三个通道保存 3 字节，alpha 恒为 255，避免预乘透明度造成字节变化。所有资源同源，导出 Canvas 不受跨域污染。

字节头共 20 字节：

| 偏移 | 内容 |
|---|---|
| 0–7 | ASCII `MEOWPNG1` |
| 8–11 | 大端 uint32：JSON UTF-8 长度 |
| 12–15 | 大端 uint32：payload CRC32 |
| 16–19 | 大端 uint32：协议版本 1 |
| 20 起 | JSON：format、version、savedAt、完整 pet 数据 |

图片内容包括姓名、出生/更新时间、四项状态、XP、星星、当前及已拥有皮肤、配饰、休息状态、互动计数。容量 86,016 字节，当前有效数据通常不到 1 KB。未使用区域填充奶油色。

生成后会把最终 PNG 重新解码并对照源数据，成功才提供下载。导入前检查 PNG 签名、512×512 尺寸、4 MB 文件上限、alpha、magic、版本、长度、CRC 和字段范围。失败不会修改现有宠物。CRC 用于检测损坏，不是加密或防作弊。不要压缩、缩放、截图、加滤镜或转换 JPG；分享时须选择原图/文件。

## 动画、性能与音频

使用 SVG + CSS transform 动画，无 WebGL、逐帧全屏 Canvas 绘制或重型游戏框架；状态每 5 秒更新一次。页面隐藏后暂停动画、结束小游戏、释放录音；支持 prefers-reduced-motion。具体流畅度仍取决于设备，已检查桌面和 320/390px 窄屏。

声音每次加载默认关闭。显式开启后可以播放合成提示音；主动点击说话并授权麦克风，最多录制 5 秒，再以 1.35 倍速/变调复述。录音只保留在内存，不进存档，不上传。录音需要 HTTPS 或 localhost；局域网普通 HTTP 通常无法授权麦克风，其余玩法可用。

## 换皮

- `assets/cat.svg`：分组的尾巴、身体、头、眼睛、嘴和配饰。保留分组 class，可直接复用现有动画。
- `model.mjs` 的 `SKINS`：颜色、名称和价格。
- `style.css`：场景、动画、响应式布局。
- 更换角色形体时，保持 viewBox 400×440 或同步修改其布局；未来改变存档结构时应增加版本并做迁移。

## 开发与验证

仓库根目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766/games/little-cat/`。测试结束 Ctrl+C。

`node --test _tests/little-cat.test.mjs`：编码解码、CRC、损坏与非法字段、状态演进、睡眠、皮肤购买。

隐藏浏览器验证：改名/喂食、下载真实 PNG、独立 origin 上传恢复、单像素损坏拒绝、毛线球奖励、休息、静音录音拦截、桌面和 320/390px 排版。没有调用真实麦克风或播放声音；真实设备录音回放与各安卓相册保存行为需在手机上验收。
